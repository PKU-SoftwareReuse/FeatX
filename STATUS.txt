Badge justification:

- Reusable: the artifact includes source code, Dockerfiles, Compose
  configuration, seed data, dataset documentation, component build commands,
  and a clear statement of which claims require external LLM credentials. It is
  documented, internally consistent, exercisable, and accompanied by smoke
  checks for the frontend, backend, MySQL seed, RepoSummary environment, and
  dataset.
- Available: the artifact snapshot is archived on Zenodo with DOI
  `10.5281/zenodo.21187017`, the GitHub artifact branch is available at

  artifact is distributed under the MIT License.

  Python RepoSummary module.

  `featx-backend:ase26`, and `featx-frontend:ase26`.
- The NBlog seeded case study is included as `datasets/mysql/featx_seed.sql`

Known limitations:

- Full LLM-backed feature extraction and code evolution require external API
  credentials and may incur provider-side cost.
- Full replay of every LLM-backed experiment is outside the quick-check path
  because model outputs, model availability, provider latency, and API cost are
  external to the artifact.
- The controlled user study reported in the paper is not re-executed by the
  artifact package.
- The first Docker build is large and slow because the backend image includes
  CPU PyTorch, sentence-transformers, and the Java backend. Locally observed
  image sizes were approximately 2.81 GB for `featx-backend:ase26`, 94 MB for
  `featx-frontend:ase26`, and 1.09 GB for `featx-mysql:ase26`.
- The sentence-transformer model may still be downloaded at runtime unless it is
  already cached or preloaded.
